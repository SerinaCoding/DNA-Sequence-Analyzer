DNA Sequence Analyzer

A simple Python project for basic DNA sequence analysis.

Project Description

This project analyzes a DNA sequence using Python.

What Does It Do?

- Calculates DNA sequence length
- Counts A, T, G and C nucleotides
- Calculates GC content

DNA Sequence

ATGCGTACGTTAGC

Tools Used

- Python
- Basic Bioinformatics

Learning Objective

This project helps practice basic Python programming and understand fundamental DNA sequence analysis.
